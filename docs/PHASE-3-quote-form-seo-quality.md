# Phase 3 — Quote form, SEO and quality pass

**Goal:** A working "Get a Free Quote" form that emails requests to the business, plus SEO basics, accessibility, performance and cross-device checks. After this phase the site is ready to show.

**Time estimate:** 1 session.

---

## What "Book now" does (decided)

Every "Book now" / "Get a Free Quote" button goes to `/quote/`. It does **not** book a calendar slot, because commercial, post-construction and move-out jobs are priced per space. The form sends the request by email, and the customer lands on a thank-you page. On mobile, the sticky bar also offers "Call".

## Claude Code: tasks

### 3.1 Quote page (`quote.ejs`)
- Two-column on desktop (form left, contact card right), stacked on mobile with the form first.
- Contact card: phone (tap to call), email, service area, hours, socials. Placeholders if TODO.
- Form fields (all with visible labels):
  - Full name* · Phone* · Email*
  - Service* (select: the 6 services + "Not sure / other")
  - Property type (select: Home or apartment, Office, Medical or dental clinic, New build / construction site, Other)
  - Approximate size in sq ft (optional number)
  - Address or area* (text)
  - Preferred date (date input, optional)
  - Details (textarea) — placeholder: "Number of rooms, condition, anything we should know"
  - How did you hear about us? (optional select)
  - Consent checkbox*: "I agree to be contacted about my quote request." with a link to the Privacy page
- Pre-select the service from the `?service=slug` query string (small JS).
- Hidden fields for Web3Forms: `access_key` (from site.json), `subject` ("New quote request — The Right Clean"), `from_name`, `redirect` to the absolute `/thank-you/` URL, and the honeypot field `botcheck`.
- Submit with a normal HTML POST to `https://api.web3forms.com/submit` (works without JS). Add JS enhancement: client-side validation messages, disable the button and show "Sending…" while submitting.
- Skip photo uploads (the free plan doesn't support attachments). Instead add a line: "Have photos? Mention it and we'll ask for them when we reply."

### 3.2 Thank-you page
"Thanks, {we've got your request}. We'll get back to you within 1 business day." (Wording "1 business day" marked TODO for the family to confirm.) Buttons: back to Home, Services.

### 3.3 SEO
- Unique `<title>` and meta description on every page (front matter).
- Open Graph and Twitter tags with a 1200×630 share image (`src/assets/images/og-image.jpg`, built from the hero image + name).
- Favicon set (from the logo) and `site.webmanifest`.
- JSON-LD `LocalBusiness` (type `HouseCleaningService` or `ProfessionalService`) on the Home page, using only confirmed fields from site.json (skip phone/area/hours if TODO).
- `sitemap.xml` generated by Eleventy from all pages except thank-you and 404.
- `robots.txt`: `Disallow: /` while `site.preview` is true; allow all and point to the sitemap when false.
- Canonical URLs using `site.url`.

### 3.4 Accessibility pass
- Check headings are in order (one h1 per page), all images have alt text, links/buttons have clear names, focus is visible, form errors are announced (`aria-live`), colour contrast passes AA, and the mobile menu works with a keyboard.

### 3.5 Performance pass
- Width/height on every image, WebP with fallback, lazy loading below the fold, hero image preloaded.
- Only load the Bootstrap JS bundle (no jQuery). Minify CSS/JS in the build if simple to add.
